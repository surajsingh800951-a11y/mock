# Mock Interview Questions — Python Basics + Git/GitHub

# Magan

### 1. What is Python and where is it used?

**Answer:**  
Python is a high-level, interpreted, and easy-to-read programming language. It is used in web development, data science, automation, AI/ML, and many other fields.

### 2. What is a variable?

**Answer:**  
A variable is a name used to store a value in memory.

### 3. What are the rules for naming a variable in Python?

**Answer:**  
A variable must start with a letter or underscore, not a number. Spaces are not allowed, variable names are case-sensitive, and reserved keywords cannot be used.

### 4. What is the difference between `x = 10` and `x = "10"`?

**Answer:**  
`x = 10` stores an integer value, while `x = "10"` stores a string value. Although they look similar, their data types are different.

### 5. How many basic data types does Python have? Name them.

**Answer:**  
The commonly used basic data types are `int`, `float`, `str`, `bool`, `list`, `tuple`, `dict`, and `set`.

### 6. What does the `type()` function do?

**Answer:**  
The `type()` function tells us the data type of a variable or value.

### 7. What is Git?

**Answer:**  
Git is a version control system used to track changes in code and manage different versions of a project.

### 8. What is the difference between Git and GitHub?

**Answer:**  
Git is a version control tool that runs locally on your computer. GitHub is an online platform used to host Git repositories and collaborate with others.

### 9. What does the `git init` command do?

**Answer:**  
The `git init` command initializes the current folder as a Git repository.

### 10. What is a repository (repo)?

**Answer:**  
A repository is a project folder that stores code, files, and the history of changes made to the project.

Answer:
