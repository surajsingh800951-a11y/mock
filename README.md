Mock Interview Questions — Python Basics + Git/GitHub
Professional Practice & Interview Preparation
This README contains structured mock interview questions for Python Basics and Git/GitHub.
Each student's name and assigned set are preserved. Every question is followed by a clear Answer section for practice and revision.

(For 8 students — each will interview one another)
Topics covered:

Python Introduction

Variables

Data Types

Git & GitHub Basics

How to use: Each student is given one Set (Set 1 to Set 8). The interviewer for that student will ask only from that set. A short "expected answer point" is given with each question so the interviewer can judge whether the answer is correct. The answer doesn't need to match word-for-word — the concept should just be clear.

Magan
What is Python and where is it used?

Answer
A high-level, interpreted, easy-to-read programming language; used in web development, data science, automation, AI/ML.*

What is a variable?

Answer
A name used to store a value in memory.*

What are the rules for naming a variable in Python?

Answer
Must start with a letter or underscore, not a number; no spaces allowed; case-sensitive; cannot use reserved keywords.*

What is the difference between x = 10 and x = "10"?

Answer
The first is an integer, the second is a string — they look the same but have different types.*

How many basic data types does Python have? Name them.

Answer
int, float, str, bool, list, tuple, dict, set.*

What does the type() function do?

Answer
It tells you the data type of a variable.*

What is Git?

Answer
A version control system that tracks changes in code.*

What is the difference between Git and GitHub?

Answer
Git is a tool (local), GitHub is an online platform where Git repositories are hosted.*

What does the git init command do?

Answer
Turns the current folder into a Git repository.*

What is a repository (repo)?

Answer
A folder/project that stores code along with its history.*

Shivam Yadav
Is Python an interpreted or compiled language?

Answer
Interpreted — it executes line by line.*

What symbol is used to assign a value in Python?

Answer
= (equal sign).*

What's the difference between Integer and Float? Give an example.

Answer
Integer is a whole number (5), Float is a decimal number (5.5).*

What is a String? How do you write it?

Answer
Text data; written in single or double quotes — "hello" or 'hello'.*

What does the Boolean data type represent?

Answer
A True or False value.*

How can you change the data type of a variable (type conversion)?

Answer
Using functions like int(), float(), str().*

What is the git clone command used for?

Answer
To bring a copy of a remote repository onto your local system.*

What does the git add command do?

Answer
Adds changes to the staging area, preparing them for commit.*

What does git commit do?

Answer
Permanently saves the staged changes to history, along with a message.*

What is the difference between a public and private repository on GitHub?

Answer
Public is visible to everyone, private is only visible to authorized people.*

Suraj Singh
What do you need to run Python code?

Answer
A Python interpreter installed on the system.*

How do you write a comment in Python?

Answer
Using the # symbol for a single line comment.*

What's the difference between a List and a Tuple?

Answer
A List is mutable (can be changed) [], a Tuple is immutable ().*

What does a Dictionary data type store?

Answer
Key-value pairs, e.g. {"name": "Raj", "age": 20}.*

What is the input() function used for?

Answer
To take input from the user, and it always comes in as a string.*

Can a variable name start with a number (e.g. 1name)?

Answer
No, it will throw an error.*

What does the git status command show?

Answer
Which files are modified/staged/untracked — the current state.*

What's the difference between git push and git pull?

Answer
Push sends local changes to the remote (GitHub); pull brings changes from remote into local.*

What is a branch in Git?

Answer
A separate line of development where you can work without disturbing the main code.*

What is the purpose of a README file in a GitHub repo?

Answer
Shows information/documentation about the project.*

Dileep
Python is case-sensitive — what does that mean?

Answer
Name and name will be treated as two different variables.*

How do you assign multiple variables in one line?

Answer
a, b, c = 1, 2, 3*

How is a Set different from a List?

Answer
A Set does not allow duplicate values and is unordered {}.*

What is the len() function used for?

Answer
Returns the length (count of items) of a string/list/tuple.*

What does the None type represent in Python?

Answer
No value / empty value.*

What does "dynamic typing" mean in Python?

Answer
You don't need to declare a variable's type — it's decided automatically based on the value.*

What does the git log command show?

Answer
The history of all previous commits.*

When does a merge conflict happen?

Answer
When two branches have different changes on the same line/file and Git can't decide which to keep.*

What does "forking" mean on GitHub?

Answer
Creating your own copy of someone else's repository under your account.*

What is a Pull Request (PR)?

Answer
A request to merge your changes into the original repository.*

Satyam
Why is Python considered a beginner-friendly language?

Answer
Simple syntax, readable like English, less code needed to get things done.*

Can a variable be reassigned? Give an example.

Answer
Yes, x = 5 then x = "hello" — both value and type can change.*

Among str, int, float — which one is mutable?

Answer
None of them — they are all immutable.*

What is a complex data type in Python? (basic idea)

Answer
A combination of real and imaginary numbers, e.g. 2+3j.*

How do you store a boolean value in a variable?

Answer
flag = True or flag = False*

What does the print() function do?

Answer
Displays output on the screen.*

What is a .gitignore file used for?

Answer
To list files/folders that Git should not track.*

What's the difference between a local repository and a remote repository?

Answer
Local is on your own computer, remote is on a server like GitHub.*

What is git checkout (or git switch) used for?

Answer
To switch branches or move to a specific commit.*

Why is writing a commit message important?

Answer
So it's clear why that change was made, making the history easier to understand.*

Vishu
What is the file extension for a Python file?

Answer
.py*

Is underscore (_) allowed in variable names?

Answer
Yes, e.g. my_name*

What is type casting?

Answer
Converting one data type into another, e.g. int("5")*

What will bool(0) and bool(1) output?

Answer
False and True*

What is string concatenation?

Answer
Joining two strings using +, e.g. "Hi" + "There"*

Can a list hold different data types inside it?

Answer
Yes, e.g. [1, "hello", True]*

What does the git branch command do?

Answer
Creates a new branch or lists existing branches.*

What is the staging area in Git?

Answer
The place where changes are kept before committing (after git add).*

What does "Star" mean on GitHub?

Answer
Bookmarking/liking a repository, showing appreciation.*

What is the git diff command used for?

Answer
To show what changes have been made in files.*

SET 7
Is Python a general-purpose or specific-purpose language?

Answer
General purpose — used across multiple domains.*

Can you use a keyword as a variable name (e.g. if = 5)?

Answer
No, keywords are reserved.*

Give an example of a float value.

Answer
3.14, 0.5, etc.*

How do you create an empty list?

Answer
my_list = []*

Why would you use a Tuple when a List already exists?

Answer
When the data should not change (fixed/constant data), a tuple is used.*

What does the id() function tell you about a variable?

Answer
The variable's memory address.*

What do you need to create a GitHub account?

Answer
An email ID and a username/password.*

What does git remote add origin <url> do?

Answer
Connects the local repo to a remote (GitHub) repository.*

Why is a version control system important?

Answer
To track code history, enable team collaboration, and roll back to a previous version if something goes wrong.*

What's the difference between a cloned repo and a newly created repo?

Answer
A cloned repo is a copy of an existing repo (with history), a new repo starts completely fresh.*

SET 8
Why is Python called a "readable" language?

Answer
Its syntax is simple like English, and it uses indentation-based structure.*

How do you print the value of a variable?

Answer
print(variable_name)*

Which function is used to check a data type?

Answer
type(variable_name)*

How do you access a value in a dictionary?

Answer
Through its key, e.g. dict["key"]*

What happens if you add a duplicate value to a Set?

Answer
It gets automatically removed — only unique values remain.*

What are int, float, bool collectively called?

Answer
Numeric/primitive data types.*

What does -m mean in git commit -m "message"?

Answer
A flag to write the commit message directly with the commit.*

What's the advantage of a central repository (GitHub) in team projects?

Answer
Everyone can work on the same code, and changes stay in sync.*

What is the master/main branch?

Answer
The default/primary branch that holds the stable code.*

In which format is the README.md file written?

Answer
Markdown format (.md)*

Quick Notes for the Interviewer (common for all sets)
Each set has 10 questions — Python intro/variables/data types (6) + Git/GitHub (4).

Suggested time limit: 8–10 minutes per interview.

If a student can't answer, give one hint, then move to the next question.

Don't expect word-for-word matching — the concept being correct is what matters.
